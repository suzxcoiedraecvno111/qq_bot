花碎机器人 (HuSuiBot) 安装说明
==============================

感谢使用花碎机器人！

安装步骤：
1. 运行 HuSuiBot_Setup.exe，按照向导完成安装
2. 安装程序会自动创建虚拟环境并安装依赖
3. 安装完成后，打开安装目录（默认 C:\HuSuiBot）
4. 将 .env.example 复制为 .env，用记事本编辑并填入：
   - SUPERUSERS：你的 QQ 号
   - LLMCHAT__API_PRESETS 中的 api_key：从硅基流动获取的 API Key
5. 确保 NapCat 或其他协议端已启动并连接到 8081 端口
6. 双击「启动机器人」快捷方式运行

有任何问题请访问：https://github.com/242605129/HuSuiBot
